# Mini_con
MUNI_CON — маленькая, но амбициозная социальная сеть нового поколения.  «Маленький, но удаленький».  Свобода общения, собственный путь, публикации, профили, музыка и сообщество людей, которые хотят быть собой.  Проект создаётся с нуля — шаг за шагом, без остановок и с большими планами.  MUNI_CON — свой путь, своя история, свои люди.
